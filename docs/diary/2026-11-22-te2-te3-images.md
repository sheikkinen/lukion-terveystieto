# Brief 012: TE2 and TE3 images

**Date:** 2026-11-22 **IDs:** brief 012, D-005, D-006

## What happened

Run 1 added six TE2 Mermaid diagrams, a Vega-Lite chart on fictional data, and 22 p-image header illustrations, one
for every TE2 and TE3 topic and both module pages. Run 2, after the TE3 exam drive, added six TE3 diagrams (explanatory
models, prevention levels, the chain of infection, service paths, the seven ethical viewpoints, the WHO action areas
applied to inequality), a schematic epidemiological-transition chart, and the site's first real-data chart: life
expectancy by sex from Statistics Finland (CC BY 4.0), with the CSV snapshot committed. Each run was rejected once over
a single illustration (worried faces; students who looked like children), which the producer redid and a separate
recheck ruled on. The brief's spend is about a quarter dollar; the €10 grant has used under $1 across both sites.

## Traps

- **Two agents ran the image tool in run 1,** so twenty pictures were paid for twice and the run log holds duplicates.
  Run 2 named one tool runner only.
- **A later agent can undo an earlier one's manifest edit.** The il-te3-04 prompt rewrite was lost between agents, so
  the log and the file disagreed. Check that the newest log line's hash matches the file on disk.
- **The renderer re-renders every SVG,** changing geometry in untouched files; restore them so the diff shows only new
  pictures.
- **Image models draw "students" as children.** Ask for young adults of 18 to 19 with adult builds and individual
  clothes.
